# DoqSeal Backend

Node.js / Fastify API — auth, organisations, projects, documents, jobs, e-sign, audit.

## Quick start

```bash
cp .env.example .env
npm install
npm run dev
```

API: http://localhost:3030 — health: `GET /health`
