# API reference

Base: `http://localhost:3030/api/v1`

| Prefix | Domain |
|--------|--------|
| `/kingdom` | Auth (OTP, social, logout) |
| `/user` | Profile, org creation |
| `/organisations` | Org details, usage, stats, audit |
| `/projects` | CRUD |
| `/documents` | Upload, list, get, file, delete |
| `/jobs` | Extraction job status |
| `/api-wickets` | API keys |
| `/envelopes` | E-sign |
| `/chat` | Proxy to ai-engine (planned) |
